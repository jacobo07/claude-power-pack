# Source — State-centric cognition: reality scan and connection log (2026-10-02)

authoritative, context compiled per invocation, workers disposable (Owner, 2026-10-02). This note

## Key takeaways

1. **The state-centric system already existed and nothing called it.** `modules/gsd_x/goal/`
   holds an append-only goal log, briefs compiled from durable state, epochs with providers, a
   zero-LLM reconciler and an independent judge. 3 goals ever, last activity 2026-09-25; no hook,
   command or scheduled task reached it (raw, "Why the goal spine is orphaned").
2. **A peer program owned half the mission.** The Cognitive Control Plane owns burn, fan-out,
   estate governor, agent floor and rollover; its P0 measured 0/219 subagents inheriting the
   parent transcript, which removed the "context firewall" plane (raw, "Sweep completed").
3. **The autonomy precondition could never hold.** It was pinned to repo HEAD, which moved every
   7.6 min (median, 79 commits / 48 h). Re-pinned to the engine's import closure: 43 of 336 commits
   in 7 days touch it (raw, "S1 SEALED"). See [[verdict-pinned-to-what-runs]].
4. **Two mutation drills were already invalid** before any change (anchors rotted by later
   rewrites): the suite read 52/54 with two clauses unguarded (raw, "S1 SEALED").
5. **One reported absence was a failed look.** "Zero goals autonomous" came from a PowerShell probe
   that rendered two object shapes in one table; the discovery code found the goal (raw,
   "CORRECTION").
6. **Connected, then proven on production.** Scheduled sweep `PP-GoalSweep`; G-001 re-proved all
   obligations unattended, including a read-only bot through the production proxy, and the
   judge passed it (see [[goal-spine-connect-not-build]]).
