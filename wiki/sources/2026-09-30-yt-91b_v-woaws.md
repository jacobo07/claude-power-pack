# "I Have Spent 500+ Hours Programming With AI"

Published 2026-01-22. Sponsored by JetBrains (Junie). Transcript is YouTube's Spanish auto-dub
(`es-US-orig` track); the original audio is presumably English — wording is a translation.

## Key points

- AI multiplies what you already know; learn to program first.
- Be specific: a three-level experiment (bare / average / fully technical prompt) — only the fully
  technical prompt ran on the first try.
- Break big tasks into small ones: "if you can't break it down, you don't understand the problem yet".
- Three-part prompt: task, background (files, docs, images), and a **don't-do** section (what not to
  touch).
- Keep a project memory file (guidelines.md / AGENTS.md): stack, commands, workflow.
- Useful MCP servers: Context7 (docs), Next.js tools, Chrome DevTools.
- Always give the AI a way to verify its work (tests, browser, CLI, CI) — and check the verifier
  itself, especially if the AI wrote it.
- AI amplifies good habits and bad ones alike.

## What it implies for PP

Interpretation: confirms rather than adds. PP already has each item: the Intent-Lock Never-Do Matrix
(the don't-do section), plan-first and micro-batching (small tasks), CLAUDE.md + memory (the memory
file), and the instrument-before-claim skill (checking the verifier). Evidence that PP's doctrine is
mainstream practice, not that it is complete.
