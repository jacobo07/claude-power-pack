# "200+ Hours of Claude Code Lessons in 14 Minutes"

Published 2026-03-25. A Claude Code guide for business owners, not developers. Five concepts: prompts,
CLAUDE.md, skills/plugins, MCP servers, context window.

## Key points

- CLAUDE.md is read every session; write your rules once.
- Skills are specialist playbooks; agents are "level two" — start with skills.
- MCP connectors "use more of Claude's memory" than a direct API call or a CLI; connect deliberately,
  not 20 at once.
- "AI context is like milk. It's best served fresh and condensed." One task per conversation.
- Keep CLAUDE.md short; point to reference files loaded when needed; keep SKILL.md lean and let
  Claude pull in the deeper material only when it needs it. → [[lean-always-loaded-context]]

## What it implies for PP

Interpretation: PP's always-loaded prefix is large ([[always-loaded-prefix-audit]]). The advice agrees
with PP's own direction since 2026-09-29 of moving rules into on-demand skills (visible in the
