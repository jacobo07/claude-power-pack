Implement D-02 for pillar C (SC-C): add the two real named windows to the 03-01 gate, each labelled with its plane and
its selection rule.
- Window L: the laptop's content-free evidence pack, a selection of 20 of 140 ledger rows. Its precision is
  population-level for the card channel. Its recall is selection-bound.
- Window G: this host's own transcripts. Invocation delivery is measured there. Opportunity is not measured, because
  gex44 has no card ledger.

Purpose: the frozen rule asks for figures "from transcripts over a named window" with n. A figure means something
only alongside its plane and its selection, and the absent channels must print as UNMEASURED, not as zero.
Output: the extended gate, the recorded window G file, and the re-rendered `C-delivery.md`.

Window G decision (planning context, Claude's discretion): the gate's L5 argv
(`python tools/test_skill_delivery.py`, no arguments) reads only committed files. Window G is a recorded
measurement inside a committed JSON file. It is not re-read at L5, for three reasons. (1) `--final` re-runs the gate
on the laptop, where gex44's `~/.claude/projects` does not exist. (2) This host's transcripts keep growing while the run
writes them, including this very session. (3) Claude Code prunes old transcripts, so the files under a fixed window can
vanish. Pinning still holds for anyone who re-measures on gex44: the window is named by `--root` + `--days` + `--end`, rows
are bounded by their own timestamps (03-01 owner bounds), and `--compare` shows that a re-run reproduces the record.
