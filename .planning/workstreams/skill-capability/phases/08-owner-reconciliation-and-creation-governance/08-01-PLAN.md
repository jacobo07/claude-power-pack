  `none` with a reason naming its card.

  rev-parse <sha>:skills>` so it goes stale exactly when a skill changes, and can be committed without staling itself.

  class `opportunity_detector` (proof the agreement check can see the detector branch), independent of what that
  member declares; so "CWST declares none" fails only COVERAGE-AGREES, and "CWST removed" fails only POSITIVE-CONTROL.
- DJ-06 (no self-enrolment): both new files are top-level `tools/*.py`, which `sc.opportunity_adapters` scans; no line

  adapters and move pillar D's and J's coverage. Fixture adapters are copied from the real committed file, never typed.
