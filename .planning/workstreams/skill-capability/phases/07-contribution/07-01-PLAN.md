- Constants:

- `fisher_two_sided(a, n1, b, n2) -> Fraction`:
  - Hypergeometric over tables with the observed margins, using `math.comb` and `Fraction`.
  - p = the sum of the probabilities of every table whose probability <= the observed table's probability. Exact
    comparison, no tolerance: the minimum-likelihood two-sided method.
  - Raise ValueError on n1 < 1, n2 < 1, or counts outside [0, n].
- `min_separable(n1, n2)`: the smallest |a/n1 - b/n2| (a Fraction) over all tables with `fisher_two_sided <= ALPHA`,
  plus the list of (a, b, p) tables that attain it. Return None when no table separates.
- `bound(budget)`:
  - Equal allocations, per D-01: k = 1..budget//2, each with `min_separable(k, k)`.
  - All allocations n1 + n2 <= budget, n1, n2 >= 1. This is Claude's discretion, recorded in the docstring: a
    "cannot separate" claim must hold for the most favourable design, so the verdict floor is the minimum over ALL
    allocations, which is never above the equal-allocation floor.
  - floor = that minimum, or None when nothing separates.
