## Defect procedure (applies in whichever task finds one)

A tool defect is exactly one of the following, in tools/tis_observed.py, tools/tis_report.py, tools/budget_monitor.py
or tools/pricing_source.py:
(a) the tool exits with a Python traceback, or with an exit code outside {0, 2}, on this host's transcripts;
(b) a reconcile check still reads MISMATCH after the rerun rule in Task 2, and the mismatch traces to the tool's
    arithmetic rather than to by_entrypoint.py;
(c) multi_entrypoint_files > 0, which breaks the one-entrypoint-per-file contract in `_calls_in`'s docstring and
    misattributes calls.
These are NOT defects, and each is recorded under `instrument_gaps:` with no code change: unpriced models (the tool
correctly returns None), ttl-assumed calls (documented as an under-statement), summary fields not split by entrypoint,
MEASURED_ZERO sessions, and stale pricing.
When a defect fires:
1. Add ONE new check to the matching gate: test_tis_observed.py for tis_observed or tis_report,
   test_budget_monitor_observed.py for budget_monitor, test_pricing_source.py for pricing_source. Use a synthetic
   fixture that reproduces the byte shape, never real transcript content. Run the gate with plain python3 and keep
   the `[FAIL]` line and rc 1 (RED). Commit only the test file.
2. Apply the minimal fix in the tool. Re-run that gate and the other workstream gates (tools/test_tis_observed.py,
   tools/test_pricing_source.py, tools/test_budget_monitor_observed.py, tools/test_prefix_inventory.py) and keep every
   pass line (GREEN). Commit the tool file.
3. Re-run the affected measurement (Task 1 step 7 and/or Task 2 steps 4-5) and replace the affected figures, keeping
   the pre-fix values in section 4.
Never edit a peer-owned file (tools/gsd_mission.py, tools/tco_compact_gate.py, token_ground_truth,
token_corpus_audit). A defect whose fix would need one stays `open`. After 3 failed fix attempts, stop and record it as
`open` (HR-ONESHOT-003). A defect in by_entrypoint.py itself is fixed in that file (selftest case first) and is not a
tool defect.
