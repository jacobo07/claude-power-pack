# Phase 1 -- incumbent measurement (W0)

## Method

- **Instruments:**
  - `tools/gsdx_reality_baseline.py` (commits a2bec412, 77fcf1e8; V-RB 16/16)
  - `tools/gsdx_goal_timeline.py` (commits 8aedb547, e9a61556; V-TL 8/8)
- **Engine commit:** `3fc8aebf2e8286dab9bf72dbb7d376f1bd6f06c9` (branch gsdx/pcc, R01 fix 58934936 included).
- **Python:** 3.12.10.
- **Host:** DESKTOP-PMT5BS8, AMD Ryzen 7 260, Windows 11. At the start (2026-10-07T13:55:49Z) `Win32_OperatingSystem` reported 3672 MB free of 32061 MB.
- **Serial runs:** one suite at a time, one child process. Nothing else was measured or tested while a measurement ran.
- **Hermetic environment per run:** each run gets a fresh `mkdtemp`. HOME and USERPROFILE point to `<tmp>/home`, GSDX_GOALS_ROOT points to `<tmp>/goals`, and GSDX_GOAL_EPOCH is removed. Only these three redirected paths are recorded on each row.
- **Guard:** `~/.claude/state/gsd-x` is fingerprinted before and after every `suites` call. The fingerprint is a sha256 digest over (path, size, mtime_ns). `sweep_heartbeat.json` is excluded by name, and a change to it is recorded as `excluded_changed`. The call exits 3 on CHANGED or UNKNOWN.
- **Statistics:** cold = the first run row of a suite in the JSONL. The report gives cold, min and max over the runs.
- **Free RAM:** `free_ram_mb` (GlobalMemoryStatusEx) is recorded on every row.
- **Shared-host caveat:** other Claude sessions and Cursor run on this host. The numbers are this host at this time, not a controlled bench. They are reported as measured, without smoothing.
- **Commands:**
  - `python tools/gsdx_reality_baseline.py suites --suite tools/<suite> --runs N --timeout S --out PHASE_DIR/01-incumbent-suites.jsonl --log-dir PHASE_DIR/incumbent-logs --label "W0 incumbent 2026-10-07"`
  - `python tools/gsdx_reality_baseline.py table --in PHASE_DIR/01-incumbent-suites.jsonl --baseline NAME=n/m... --md-out PHASE_DIR/01-incumbent-suites-table.md`
  - (PHASE_DIR = `.planning/workstreams/gsdx-pcc/phases/01-w0-reality-baseline-and-incumbent-measurement`)
