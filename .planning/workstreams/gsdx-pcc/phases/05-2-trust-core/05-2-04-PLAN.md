## Semantics (decided in CONTEXT item 10)
A certificate records, per contract element, `{fingerprint, environment, gate_pin}`. At validation each element is observed against the tree; element state = INHERITED when its own premises are equal, STALE when one changed, UNKNOWN when one is unknown. The claim state = `combine_states(op, element_states, k)` with `k = contract["k"]` for QUORUM. Only FRESH/INHERITED skips. A non-AND certificate with no `element_premises`, or a count that disagrees with the contract, re-runs.
