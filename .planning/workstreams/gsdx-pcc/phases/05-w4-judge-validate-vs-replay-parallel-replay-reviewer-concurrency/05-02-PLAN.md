# 05-02: bounded parallel REPLAY

## The bound (named)
`bound = min(frontier.bound(state)   # posture ECONOMY 1 / BALANCED 2 / WALL_CLOCK 4, lowered by max_parallel
            , memory_bound(free_ram_mb())   # >=3072 MB: 4; >=1536 MB: 2; below, or unreadable: 1
            , env GSDX_REPLAY_MAX if a positive int)`,
and `1` when `frontier.frontier_enabled()` is false (`GSDX_FRONTIER` off or `FRONTIER.off`). Default posture is
ECONOMY, so a goal that never declared a posture replays serially exactly as today. Memory only ever LOWERS the
bound; it is re-read at each judge call, never cached. Two replays overlap only if `proof.independent` holds for
`frontier.gate_unit` of both (undeclared -> serial; two `integration` gates share `integration-env`).

1. **RED** `tools/test_gsd_x_goal_replay_parallel.py`, summary `GSDX_REPLAY_PARALLEL_PASS=n/n  threshold=n/n`.
   Concurrency is proven by RENDEZVOUS, never by timing: each gate writes its own marker and waits (bounded 20 s)
   until the other's marker exists; a serial run times out and the gate fails. Gates:
   - `V-RP-SERIAL-IS-DEFAULT` ECONOMY: rendezvous pair cannot meet, receipts equal the legacy loop, bound 1.
   - `V-RP-OVERLAPS-UNDER-BOUND` BALANCED + injected free RAM 8192: the pair meets, PASS.
   - `V-RP-RECEIPT-EQUALS-SERIAL` same goal, bound 4 vs bound 1: identical `verdict`, row order, `exit_status`.
   - `V-RP-BOUND-NEVER-EXCEEDED` six gates each holding a counter: max observed concurrency == the bound.
   - `V-RP-RESOURCE-SERIALISES` two `integration` gates never overlap (start/stop intervals disjoint).
   - `V-RP-UNDECLARED-SERIALISES` a REALITY obligation with no runtime class stays serial.
   - `V-RP-MEMORY-LOWERS` injected free RAM 2048 -> bound 2; 1024 -> 1; `None` -> 1 (unknown escalates safe).
   - `V-RP-KILL-SWITCH` `GSDX_FRONTIER=off` -> bound 1 whatever the posture.
   - `V-RP-BOOL-CAP-IGNORED` `max_parallel: True` does not cap to 1 nor raise the bound.
   - `V-RP-ALL-JOINED` one gate times out (UNJUDGEABLE) while others run: every started gate has finished (its
     end marker exists) when `judge()` returns; the verdict is UNJUDGEABLE.
   - `V-RP-PIN-REFUSAL-IN-ORDER` a pin-refused obligation between two replays keeps its row position.
