# 03-03: `decide` becomes the first action of the compiled frontier

Goal: wire the frontier into `decide` with exact legacy equality when off or when there is nothing to parallelise.

## Tasks (RED first)
1. **RED** (the first RED-list item, "global WAIT with independent work"): add gates; run against current `decide`; V-FRONTIER-GLOBAL-WAIT must FAIL because legacy returns WAIT. Log `03-03-red.log`.
2. **GREEN**:
   - `reconcile.py`: rename the current `decide` body to `_decide_legacy` (code unchanged); new `decide(ctx)` with the same signature: `if not frontier.frontier_enabled(): return _decide_legacy(ctx)`; else `return frontier.decide_frontier(ctx, _decide_legacy)`. Import frontier lazily to keep the import graph shallow.
   - `frontier.decide_frontier(ctx, legacy)`:
     1. `base = legacy(ctx)`.
     2. If `bound(ctx) == 1` and fewer than two open epochs: return `base` (the default-posture and one-epoch case is therefore legacy-equal by construction).
     3. If `base.kind == WAIT` and the cause is an in-flight/unobservable epoch: scan ALL epochs; return the first RECOVER (dispatching) or HARVEST (ended/lost observation) ahead of any WAIT (frontier never hides an ended epoch behind a running sibling).
     4. Else if still WAIT and `len(open) < bound` and the execution frontier has a unit independent (`proof.independent`) of every open epoch's stored `unit`, and the legacy checks that precede step 5 (stop, closure, blocked_on, budget) would not have returned something other than WAIT: return the same NEXT_EPOCH `Decision` shape legacy step 5 builds (same `spec`, `info_key`), with `spec["unit"]` set.
     5. Otherwise `base`.
   - WAIT only when the execution frontier is empty or every candidate conflicts while epochs are in flight.
3. Run the whole suite and `tools/test_gsd_x_goal_reconcile.py` unchanged.

## Gates
- V-FRONTIER-GLOBAL-WAIT (RED 1): one running epoch (RUNNING observation), one independent ungated obligation, posture WALL_CLOCK: legacy WAIT, frontier NEXT_EPOCH naming the independent obligation with `spec["unit"]`; control: the same goal with the independent obligation conflicting (shared resource) still WAITs.
- V-FRONTIER-LEGACY-EQUAL: switch OFF, and switch ON with default posture, give field-equal `Decision` (all 8 fields incl. `reason`) to `_decide_legacy` over (a) every ctx the existing reconcile suite builds, (b) every log prefix of the committed Phase 2 corpus, counts printed.
- V-FRONTIER-SIGNATURE: `inspect.signature(decide)` is `(ctx: Context) -> Decision`.
- V-FRONTIER-HARVEST-NOT-HIDDEN: epoch A running, epoch B ended, bound >= 2: frontier returns HARVEST B; legacy returns WAIT (control shows the bug it fixes).
- V-FRONTIER-NO-STARVE (research P5): obligation with an open epoch is never re-selected; the next distinct obligation is.
- V-FRONTIER-WAIT-ONLY-EMPTY: with epochs in flight and a non-empty independent frontier the result is never WAIT; with it empty it is WAIT.
