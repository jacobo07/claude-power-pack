# 03-02: measured priors, ordering signals, postures, worker classes

Goal: the execution frontier gets a lexicographic order from MEASURED log data and a dispatch bound from the goal's declared posture. Still not wired into `decide`.

## Tasks (RED first)
1. **RED**: add the gates above to the suite; run; FAIL for the right reason (function absent). Log `03-02-red.log`.
2. **GREEN** in `frontier.py`:
   - `duration_prior(state, obligation)`: median `ENDED.ts - RUNNING.ts` over that obligation's own gate epochs, else median across the same gate class, else `None`.
   - `failure_risk(state, obligation, units)`: measured fail fraction x (1 + open claims sharing a read); `None` without history.
   - `info_gain(state, obligation)`: binary entropy of measured pass fraction / duration prior; `None` if either unknown. Separate function, separate field.
   - `critical_path(frontier edges, priors)`: longest known-duration chain through the graph; a unit with unknown duration marks the path `UNKNOWN_DURATION` and is sorted first (CONTEXT D28).
   - `order_key(unit)`: tuple (critical contribution desc, failure risk desc, info gain desc, legacy index), unknowns defined explicitly, never coerced to 0.
   - `posture(ctx)`: `ctx.budget` then `ctx.state.budget` key `posture`, in {ECONOMY, BALANCED, WALL_CLOCK}, absent/other = ECONOMY. `bound(ctx)`: 1/2/4 capped by `max_parallel`; an invalid or <1 `max_parallel` is ignored (bound >= 1).
   - Worker classes: `cognitive`, `deterministic`, `environment`, `reviewer`, `speculative`; `class_bound(class, ctx)`: deterministic = `bound`, environment = 1 per exclusive resource, others 1.
3. **Round-trip check (research P22)**: gate V-FRONTIER-POSTURE writes `posture` through `contract.set_budget` on a real GoalLog and reads it back via `gc.project`.

## Gates
- V-FRONTIER-PRIOR: synthetic log with known RUNNING/ENDED timestamps gives exact medians; no history gives None; per-class fallback used only when the obligation has none.
- V-FRONTIER-ORDER: order changes ONLY by the stated key, signals stay separate fields; a unit with a high info gain but low failure risk sorts after a high-risk one; ties keep legacy insertion order (control).
- V-FRONTIER-FAILURE-FIRST: obligation with prior failures sorts before one with none.
- V-FRONTIER-INFOGAIN: entropy 0 at p in {0,1}, max at 0.5, None on unknown duration.
- V-FRONTIER-CRITICAL-PATH: chain durations summed; unknown duration reported UNKNOWN, never 0.
- V-FRONTIER-POSTURE: ECONOMY=1, BALANCED=2, WALL_CLOCK=4, absent/garbage=1, cap respected, round-trip through the log.
- V-FRONTIER-CLASSES: all five classes have a bound; speculative/cognitive never exceed 1.
