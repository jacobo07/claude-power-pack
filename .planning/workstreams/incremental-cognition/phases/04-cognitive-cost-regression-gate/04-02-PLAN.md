Attribution rules (binding; stated heuristics per CONTEXT discretion):
- `registrations(settings_path)` -> {event: set(command strings)}; a missing file -> {} (measured empty); unreadable
  or malformed JSON -> None (unknown).
- `command_scope(cmd, ctx)`: "${CLAUDE_PLUGIN_ROOT}" in cmd -> universal (basis plugin); in project registrations
  (any event) and not in user registrations -> project; in user registrations and not in project -> universal;
  otherwise -> unattributed. Any needed registration set None -> unattributed.
- `correlate_hook(element, event, field, window_rows)` -> the set of commands of hook_success rows with that
  hookEvent whose decoded stdout[hookSpecificOutput][field] (field additionalContext) or stdout[field] (field
  systemMessage) equals the element; undecodable stdout is skipped.
- `hook_scope(...)`: exactly one command -> command_scope; several -> unattributed; none -> event fallback
  (project regs for the event non-empty and user regs for it empty -> project; project regs known and empty ->
  universal; both non-empty, or either None -> unattributed). Source label = the command, else `event:<Event>`.
- `scope_for_name(kind, name, ctx)` for kind skill | agent: project candidates `<cwd>/.claude/skills/<name>/SKILL.md`,
  `<cwd>/.claude/commands/<name>.md` (a `ns:rest` name -> `commands/<ns>/<rest>.md`) for skills,
  `<cwd>/.claude/agents/**/<name>.md` for agents; universal candidates the same under `<install_home>/.claude/`;
  hit in both -> unattributed; project only -> project; universal only -> universal; neither: a `ns:rest` name ->
  universal (plugin namespace; no project file claims it), else unattributed. Directory listings cached per run.
- ctx unavailable (cwd or install_home None, or not an existing directory on this host) -> every rule above returns
  unattributed with basis `not_on_this_host`.
