bundle will tell the Owner to run `python3 tools/test_incremental_cognition_program.py --pillar J` after adding
owner_ledger evidence, but the wrapper's `--pillar` branch (tools/test_incremental_cognition_program.py main, the
`if pid in ce.PILLARS` block) runs only R3 and R4. R2 runs only under `--final`, and the CE clause L4 accepts any
`owner_ledger` row without reading it (`_check_evidence` returns [] for a kind outside FILE_KINDS). A J terminal with a
misquoted owner terminal would therefore print `ICP_PILLAR_J=PASS`. This plan makes `--pillar <P>` run R2 for P
(documented-capability rule: the documented check must execute what it claims).
