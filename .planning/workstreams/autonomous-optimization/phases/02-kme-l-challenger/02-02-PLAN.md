Per orchestrator decision 2 (cross-project metric = transcript bytes; whole-corpus index bytes are their own column)
and CONTEXT discretion (exposure = files actually opened):

1. `tools/strace_io_sum.py` (stdlib only), subcommand `sum LOG --corpus-root R [--scope-regex RX] [--forbid-regex RX]
   [--index-path P ...] [--json]`: parse `openat` (successful only, path from the `= N</abs/path>` annotation),
   `read` / `pread64` / `readv` / `preadv` return values attributed to the `<path>` fd annotation, with
   unfinished / resumed pairing by PID. Columns: `raw_bytes` (bytes read from regular files under R ending `.jsonl`),
   `raw_files_opened` (distinct such paths opened), `unique_bytes` (sum of `os.stat().st_size` over distinct
   `(st_dev, st_ino)` of those paths, stat taken at summary time; a path that no longer stats is listed under
   `unstattable`, never counted as 0), `cross_project_bytes` (raw bytes on paths whose first component under R does not
   match `--scope-regex`; `null` when no scope regex is given, meaning not measured), `forbidden_bytes` and
   `forbidden_opens` (full-path match of `--forbid-regex`, default `(?i)costaluz`; opens include directories),
   `index_bytes` (bytes read from each `--index-path` and its `-wal` / `-shm` / `-journal` siblings), `other_bytes`,
   `by_project` `{project: {bytes, files}}`, `syscalls_parsed`, `lines_unparsed`. `verdict` is `MEASURED`, or
   `UNMEASURED` with exit 3 when `syscalls_parsed` is 0. Output is one JSON object; it prints paths and numbers only.
2. Subcommand `run --label L --repeat N [--trace-repeat K] [--trace-dir D] [--evict PATH ...] [--ok-exit C ...]
   --step 'ARGV' [--step 'ARGV' ...] [sum options]`: each repetition runs every step in order (`shlex.split`, no
   shell, stdout / stderr to files under `--trace-dir` or discarded), wall per step and per query by
   `time.monotonic`; before each repetition, when `--evict` is given, every regular file under each PATH (a file or a
   tree) is opened read-only and `os.posix_fadvise(fd, 0, 0, POSIX_FADV_DONTNEED)` is called (best effort; counts
   evicted / failed are reported and the run is labelled `cache: evicted best-effort, residency not measured`). The
   N untraced repetitions (N may be 0 for a traced-only call) give `wall_runs` and `wall_median_s` (FAILED runs
   excluded and listed; `null` when N is 0, never 0). The K traced
   repetitions run each step under the strace capture shape above into `D/<label>-r<i>-s<j>.strace` and are summed
   with `sum`; the result lists each traced repetition and `open_set_identical` (the sets of opened corpus paths agree
   across the K repetitions). Output: one JSON object `{label, steps, n, wall_runs, wall_median_s, failed, traced,
   open_set_identical, cache}`.
3. `tools/test_kme_measure_tools.py`: plumbing mirrors the repo convention; summary `KMET_PASS=n/m  threshold=m/m
   skipped=s  inconclusive=i`; synthetic logs are written into a tmp dir by the test. Gates per `<behavior>`.
