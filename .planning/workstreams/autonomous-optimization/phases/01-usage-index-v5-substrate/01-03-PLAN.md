In tools/usage_index.py, inside the single pass (`_v5_line` and the refresh state; no second reader):
- Timestamps: state `last_ts` starts from the file's stored `last_ts` when resuming at a non-zero offset; a line with a
  parseable timestamp (existing `_epoch`) updates it; every v5 row written for a line uses the line's own timestamp,
  else `last_ts`, else NULL. `files.first_ts` is set from the first parseable timestamp when it is NULL; `files.last_ts`
  is the last one seen. call_files.ts follows the same rule for the call's line (stash the effective timestamp per call
  key in state from `_v5_line`, use it when the returned call has no timestamp).
- Recorded cwd: every line with a non-empty string `cwd` upserts file_cwds (file, raw cwd string, first_off = min,
  first_ts of that first occurrence); state `cwd` keeps the normalized current cwd for `_norm_path` joins.
- Pattern registry: `PATTERN_SOURCES = (("kme", "wiki/tools/kme_token_audit.py", "KME_RE"),)`; `_load_patterns(con)`
  imports each source once per process through `importlib.util.spec_from_file_location` relative to `_PP_ROOT`, takes
  the compiled object's `.pattern` and `.flags` (never a copied literal), upserts the `patterns` table with a version
  (first 12 hex of sha256 over pattern and flags), and writes meta `pattern_set` (sha256 of the sorted name/version
  pairs). On any load failure: no rows, `pat_ver` NULL for files ingested in that pass, and `pattern_error` in the
  refresh result and meta last_refresh_status. Each ingested file stores `pat_ver` = the pattern_set in force.
- `pat_hits` on tool_events: for each registered pattern, `len(compiled.findall(json.dumps(input, ensure_ascii=False)))`
  (the champion's serialization, distinct from the canonical one used for input_hash); JSON object of the non-zero
  counts, NULL when all are zero.
- `user_hits`: on `type == "user"` lines with `isMeta` falsy, take the str content or each `text` item of list content,
  apply the champion's three text guards per text, sum hits per pattern over the qualifying texts of the line, insert
  (file, offset, effective ts, JSON) only when a count is non-zero.
- Add `user_hits` and `file_cwds` rows to the rewritten-file restart deletion (already listed by 01-01; verify).
