Governing spec: vault/specs/autonomous-optimization.md. Answer of record for the AOP-O edge probe ("if interrupted or run
in parallel, what is guaranteed?"): each file is ingested in its own `BEGIN IMMEDIATE` transaction that first re-reads the
file's `files` row (offset, size, mtime_ns) and compares it with the snapshot the pass started from; when another writer

last_refresh_status. The migration keeps its in-transaction version re-check.
