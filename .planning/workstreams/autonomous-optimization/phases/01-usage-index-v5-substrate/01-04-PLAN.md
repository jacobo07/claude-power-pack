Complete `population(con, *, until=None, project_filter=None, select=None, include_archived=False, expected=None,
host=None, tolerate_parse_errors=False, detail=False)` in tools/usage_index.py. It reads the DB only (no transcript open).
- Scope: files whose `store` (live) or `project` (archived) matches `project_filter` by `re.search`; sessions keyed by
  (archived, project, session_key). With `until`, a v5 row's effective time is `COALESCE(ts, files.first_ts)` and only
  rows with effective time <= until count; a session exists only when the minimum first_ts of its files is <= until.
- Features per session: tool_uses = tool_events rows, tool_uses_kme = rows whose pat_hits names "kme", user_kme_hits =
  sum of user_hits "kme", project = the session's project, cwd = the raw launch cwd (smallest first_off of the main file
  among rows with first_ts <= until; else the subagent files in path order). Selection when select is "kme":
  `_kme_selector(host)` loads `wiki/tools/kme_token_audit.py` (classify) and `wiki/tools/kme_report.py` (is_kme) by file
  path and applies them to a feature dict with the keys they read; thresholds are never copied. Select None = all.
- Calls per session from call_files (occurrence view; duplicate files included, as the champion counts them), summed
  per field; sessions_dead = selected sessions with 0 calls.
- Archived: excluded unless include_archived; twins (archived and live with the same project and session_key) always
  resolve to the live session; both reported in the reconcile block.
- Refusals -> verdict UNMEASURED with a `reasons` list: no session in scope; any in-scope file with v5_from NULL or > 0;
  parse_errors > 0 unless tolerate_parse_errors (then `parse_errors_tolerated` = total); any files.error; when select
  uses patterns, any in-scope file whose pat_ver is NULL or differs from meta pattern_set.
- Verdict: EXACT when every field of `VERDICT_FIELDS = ("sessions_active", "sessions_dead", "calls", "cache_read")`
  equals `expected`, DRIFTED otherwise with `deltas`; `secondary` reports input, cache_write and output observed vs
  expected with a per-field `match` flag (reported, never folded into EXACT); MEASURED when expected is None.
- Reconcile block: `unique` (distinct keys across the selection's occurrences, per-field max), `shared_outside` (keys of
  the selection also present in call_files of files outside it: count, cache_read, up to ten (project, session_key)),
  `first_writer` (calls rows whose calls.file is a selected file and ts <= until: count and cache_read; the v4
  order-dependent figure), `dup_files_in_scope`, `archived_excluded`, `archived_twins`, `skipped_shapes` (meta),
  `per_project` rows (project, sessions_active, sessions_dead, calls, cache_read). `detail=True` adds per-session rows
  (project, session_key, class, share, selected, calls, cache_read).
- CLI `population`: `--until ISO`, `--project-filter REGEX`, `--select {all,kme}`, `--include-archived`, `--host`,
  `--tolerate-parse-errors`, `--expect KEY` with `--expect-file` defaulting to `DEFAULT_DENOM_FILE` (the frozen KME-L
  record path), repeatable `--perturb FIELD=INT`, `--detail`, `--plane LABEL` echoed in the output as `plane`.
