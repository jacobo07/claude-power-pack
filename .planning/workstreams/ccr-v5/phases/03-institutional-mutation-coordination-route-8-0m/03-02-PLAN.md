<objective>
Extend the existing lease ledger from a class mutex to resource leases (resource id, intent, expected base revision, writer identity) and add the writer probe for a dirty shared path.

Purpose: ROADMAP Phase 3 clauses 1 and 2. The ledger (modules/lease/store.py) already gives fenced, TTL-bounded, all-or-none exclusion keyed by an opaque class string; resource leases are that same machinery keyed by a normalized repo path with the intent, base revision and writer carried in the grant record. The probe is the only new file because grep found no owner for "who is writing this path": registry readers return live rows only (tools/ccr_release.live_sessions) or a tri-state per session (gsd_long_run.session_liveness), and none returns dead rows or ties a session to a path.
Output: extended store, tools/writer_probe.py, RLEASE_PASS=16/16 and WPROBE_PASS=12/12, an anchor file for rollback.
</objective>

  Pinning rule (the core): the file's last-write time M is its filesystem mtime; if it cannot be read (deleted, error) the verdict is UNKNOWN. A strong event is an assistant tool_use of a file-writing tool whose file path resolves (normcase and normpath) to the target; a weak event is a shell tool_use whose command text mentions the repo-relative path in either slash form.
