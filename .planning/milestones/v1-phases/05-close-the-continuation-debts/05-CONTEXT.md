   nothing. It lives in the VS Code extension, unreachable from the Python
   gates, so it currently rests on a single Owner observation of one pane. If a
   future build changes the completion-popup behaviour, the tail becomes a stray
   message in every crossing and no test says so.

   `gsd-autorun-intent-ghost-*.json` fixtures, and
