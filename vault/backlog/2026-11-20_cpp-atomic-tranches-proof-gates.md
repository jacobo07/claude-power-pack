## 5. Admission gates and explicit Owner-only boundaries

- External network/credential/third-party install: license, trust and sandbox review; no automatic install via copied SKILL.md.
- Host-global `~/.claude/settings.json`/permissions/hook registration: current CPP HR-001, actual owner authorization and true live wiring; no auto-mod workaround.
- API-paid calls / model budgets: honor Owner subscription/quota/authorization; no hidden API pricing and no silent new models.
- Money, sending messages, deployment, data deletion, irreversible schema migration: effect-specific explicit Owner authority and a clear rollback/compensation boundary.
- Security gate changes, global baseline promotions and evaluator/heldout modifications: protected reviewer and authorized decision; never self-approve.
- Private project knowledge crossing into public CPP: classify/redact, license and tenant consent; no copy of private customer data.
- Multiple active writers: lease/worktree owner, path-scoped commits, no broad cleanup or untracked-file destruction; preserve session continuity.

If unavailable tools, return UNJUDGED with exact blocking boundary and a host-verifiable reproduction path when approved; never assert external execution.

## 6. Minimum proof package for every new behavior

1. Goal/intent and unchanged acceptance; target revision and source evidence.
2. Identified existing owner/consumer and delta; no competing authority.
3. Applicability, preconditions, invalidators and explicit fail cases.
4. Minimal implementation evidence with path/hash/commit and permission receipts.
5. Unit + system-integration/real-runtime proof as required by claim.
6. Positive + negative + mutation/chaos where relevant (especially critical guards).
7. Independent judge/gate identity and pinned executable target, not builder-only prose.
8. Regression/affected-proof closure and no weakened denominator/threshold.
9. Cost + latency + privacy + maintenance attribution if optimization claimed.
10. User/Owner approval only where needed, rollback/replay/retirement plan.
11. Institutional record/UKDL only if the generalized pattern is valid and transferable; archive rejected hypotheses.
12. Real repeated-consumer observation; route regression tests ensure a new skill is not inert.

**A documentation backlog commit meets only intake obligations**. No other rung is awarded by this operation.

## 7. Quantified metrics — NO fabricated thresholds

| Metric / indicator | Required denominator and safeguards |
| --- | --- |
| Effective Capability Coverage | Applicable discovered capabilities with real consumer and proof / all applicable discovered, N/A+UNKNOWN separate |
| Verified First-Pass Success | Tasks with independent correct proof first try / actually graded comparable tasks |
| Regression Escape | Observed regressions past protective gate / relevant verified releases, confidence bounds |
| Cognitive Cost per Verified Outcome | All measured model/context/tool/coordination cost / correctly proven tasks |
| False Activation | Invalid domain wakes / evaluated negatives, split by language, host and task type |
| Knowledge Miss | Expected relevant prior patterns not recovered / verified eligible recall tests |
| Stale Proof and Unowned Effect | Number/rate over observed real applicable events, no missing data hidden |
| Autonomous Recovery | Correct recovery with no duplicate unauthorized effect / executed fault-injection trials |
| Resume Archaeology | Total read/time/context after cold restart / comparable missions |
| Institutional Reuse/Knowledge-to-Behavior | *Actually applied and beneficial* verified eligible patterns / eligible opportunities; read and citation separate |
| Cognitive Capitalization / Decision Extinction | Verified reusable work/avoided cognitive decisions per comparable workload, not prompt count |
| Work-Class Learning Plateau | Marginal verified cost across repetitions with novelty and proof strength controlled |
| Developmental Compression | Comparable original trajectory verified cost / new verified cost (reject hindsight leakage) |
| Embodied Knowledge | Relevant institutional claims handled by certified lower-model mechanisms, not number of tools |
| Evolutionary Change Confidence | Appropriate migrations preserving required traits / executed comparable migration trials |
| Institutional Capitalization Efficiency (ICE) | Proven future value / build+maintain+proof costs; if forecast uncertain, report bounds or unknown |
| Transition Precision/Recall and Maturity Lag/Overshoot | Changes justified by observed invalidated premise and outcomes, not code volume |
| Cognitive Roofline | Classify current limiter: cognition, context, verification, runtime, memory, coordination, authority, reality, knowledge |

**Thresholds** must be predeclared using baseline A/A noise, project impact, runtime limits and risk; do not copy universal values. High safety invariants (secret non-exposure, no unauthorized effect, no stale fence writes) demand explicit zero-violation tests in the tested scope, not probabilistic excuses.
