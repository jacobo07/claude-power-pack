# b2b_dashboard (fixture)

Rutaviva is an invented business, created only as a CDIO cross-sector benchmark fixture. It does not imitate any real company. All figures, routes, shipment IDs and client names are made-up sample data and the page labels them "Datos de ejemplo".

Surface: operations dashboard for a B2B logistics SaaS (KPI row, one line chart, one table). Static HTML/CSS, one typeface (Inter via Google Fonts), one accent colour, no JS, no forms.
