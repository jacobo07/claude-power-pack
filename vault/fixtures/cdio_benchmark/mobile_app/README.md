# mobile_app (fixture)

"Vuelta" is an invented reading-habit tracker, made only as a fixture for the CDIO cross-sector benchmark.
It is not a real product and does not imitate one. The book, the author and every number on screen are
sample data and carry the label "Datos de ejemplo". Nothing collects real data.

Three screens drawn at 390x844 without a device bezel: onboarding, home, book detail.
Judged under CDIO-08 (mobile app surface). Static HTML/CSS, Google Fonts only (Source Serif 4, Inter).
