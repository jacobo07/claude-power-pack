# METHOD-OUTCOME-RULE two failures with the same approach: switch approach before another attempt

When the last two attempts with the same approach (method family) each produced no improvement (certified nothing, fixed nothing,
no gain), a third attempt that repeats that approach again is the expected-failure branch. Retrying, tuning the same parameter,
rotating, re-running the same template or a bigger pool is the same approach. Switch to a different approach, or change the
problem definition, before trying again. Source: GSDX-CME policy CME-B1, evaluated on 14 reconstruction attempts (see the
METHOD-OUTCOME-* outcome files); evidence is advisory (n small, negative control non-discriminating).
