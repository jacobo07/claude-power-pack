# CLAE — Open Questions

> **What this file is.** Part XXVI §5 defines the twelve companion artifacts as *"extracts for retrieval convenience"* — the schemas, consolidations and measured counts live in the Parts. This file locates entries; it does not restate, resolve or extend them.
> **Reading rule.** Every row cites the Part that seeded it. Where a row's source is ambiguous, the ambiguity is transcribed rather than resolved.

Part XXVI §9a selects the open questions that matter; this file carries all of them, in Part order, with the epistemic label each records.

## 3. Reading

Every Part from II to XXV carries exactly three open questions except Part II, which carries four. A uniform count across twenty-four Parts is worth naming: it is consistent with a section written to a template as much as with a doubt measured per Part. Part XXII §16 raises the analogous concern about its own trap count. Neither is resolved here.
