# Escenarios de aceptación — MYTILUS

1. Visitante español desde Google Maps. Sin conocer la marca, identifica tipo de comida, dirección verificada, horario y forma correcta de reservar. No encuentra datos pendientes o contradictorios.
2. Turista en móvil. Abre la carta, entiende los platos y los precios reales, cambia idioma cuando esté disponible y vuelve a reservar sin perder contexto.
3. Pareja desde redes sociales. Comprueba mediante fotos auténticas el ambiente y decide si encaja con la ocasión. No se hacen promesas falsas de vistas o servicios.
4. Usuario con teclado. Recorre navegación, galería, carta y formulario sin bloqueos. Los elementos sticky no ocultan foco ni contenido.
5. Usuario con reduced motion. Todas las funciones son equivalentes, aunque los efectos desaparezcan.
6. Usuario solicita mesa. La web informa correctamente si se ha enviado una solicitud, si está pendiente y, solo con evidencia del backend, si está confirmada.
7. Dispositivo pequeño. CTA persistente no tapa texto, contenido, botón de volver ni controles esenciales; prueba real requerida.
8. Marketing/propietario cambia un dato validado de carta u horario. La fuente única evita discrepancias, con tests de regresión en rutas.
