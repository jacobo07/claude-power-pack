# Harbour Tide Letter: landing page

Static HTML and CSS. No scripts, no build step, no animation.

- Palette: sea-grey ink `#1f2d36` on paper `#f6f4ef`, accent `#1d5a73` (contrast 7.4:1 on paper).
- Type: system serif for headings, system sans for body, 18px base, line-height 1.6.
- One action: "Sign up by email" opens the reader's mail app with a prepared message.
  There is no server, so the page does not promise an instant confirmation.
- Footer links to privacy.html and terms.html.
