1. levels.py: `register_src(rows, registry=SRC_REGISTRY, src_dir=SRC_DIR)`. Reads the current registry; every existing row
   is kept byte-identical (same dict, same order key `id`); each new row {id, name, source_path=<src_dir>/<name>.c,
   source_sha256, preset, origin} comes from src_intake()'s would_register plus the donor `source` text from DONORS.jsonl.
   Refuse (Refused, nothing written) on: an id already present with a different source_sha256; source text whose sha256 !=
   the row's; a name that would overwrite an existing different .c file. Writes source files first, then the registry, with
   I.atomic_write, same JSON layout as seed_src (indent=1, sort_keys, trailing newline). Idempotent: a second call with the
