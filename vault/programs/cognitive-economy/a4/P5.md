  `CPP_ARM_WORKER_GUARD` is `off`. Otherwise, if any record from `all_missions()` has `(rec.get("owner") or {}).get("session_id") == sid`
  (ANY state: a worker can outlive its `done`), return
  `worker_arm_launch_refused: session <sid[:8]> is the worker of <mission_id> (<state>); a worker arms only with --no-launch`.

  `why = worker_arm_refusal(os.environ.get("CLAUDE_CODE_SESSION_ID"))`; if why: `lr.ledger_append("arm-guard", "worker_arm_refused", why=why[:300])`
  (match the existing ledger_append signature you see at 3572) and `raise MissionError(why)`. Nothing is created on refusal.
