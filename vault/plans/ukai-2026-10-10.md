## Gaps actually shown (not assumed)
1. **No delivery record.** Recall writes only a `shown/` dedupe set. Nothing records what was
   injected for which prompt, so retrieved, delivered and used cannot be told apart. (Frontier H.)
2. **No evaluation.** Recall has unit gates (V-RECALL-*) but no independent query set, and no
   with/without comparison. Recall@k, precision and stale exposure are UNKNOWN.
3. **Scope isolation is unproven.** Memories from all 12 projects go into one index with a
   current-project boost, not a filter. Whether a private fact from project X can surface in
   project Y has no negative test. (Section VI.)
4. **Uncovered stores.** Graphify coordinates, validated KACQ outputs and capability_runtime
   contracts are not recall sources. The gap is measured only after F0 builds the eval set.
5. **Lexical only.** Different vocabulary (ES prompt vs EN rule) is a plausible miss. Whether it is
   a real one is decided by gap 2's eval set, not now.

## Phases (all EXECUTION mode after approval)
- **F0 Eval set + baseline.** About 60 labelled queries (software, ecommerce/TUA-X, ops, docs,
  cross-domain, ES/EN), written from known memory/rule answers. Each query lists the files that
  should come back, the files that must not, and a scope label. A harness measures recall@5,
  precision@5, stale and cross-scope exposure on the live index. Baseline numbers get recorded.
- **F1 Delivery ledger.** recall writes `shown.jsonl` (prompt hash, session, cwd scope, chunk ids,
  scores, latency). It appends, never blocks, and fails open. A Stop-side reader marks whether an
  injected path was then opened or cited in the turn. That gives "considered", the only frontier
  the harness can observe.
- **F2 Scope isolation.** Each memory carries a privacy class (global / project-private). Private
  chunks are filtered out, not just ranked lower, outside their project. Negative test: a planted
  private memory never surfaces from another cwd. Control: it does surface from its own cwd.
- **F3 Federation by eval evidence.** Add Graphify coordinates and other stores as recall sources
  only where F0 queries miss them. Each source gets a positive/negative V-gate.
- **F4 Vocabulary bridge, only if F0 shows misses.** A cheap ES/EN synonym and alias expansion
  comes first. Embeddings only if that falls short on the eval set.
- **F5 Freshness/adversarial.** Deleted source, edited source, revoked/private, duplicate,
  injection text inside a chunk (stays labelled as data), concurrent refresh, crash mid-refresh.
- **F6 Baseline ratchet + fresh-agent test.** Add the delivery ledger, eval harness and scope
  filter to the construction baseline owner (verified at that point, not assumed), plus UKDL
  entries. A fresh session finds and runs the harness from the docs alone.
- **F7 Independent review.** pp-code-reviewer plus oneshot-architect-auditor on the diff. Re-run
  every gate.
